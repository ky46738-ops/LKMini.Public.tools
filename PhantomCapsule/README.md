## 現行定義

幻影膠囊是 `EmptyContainer｜空容器`：它不靠容量成立，也不等於 ZIP、資料夾、網頁或任何單一副檔名。它可以用無附檔名檔案承載 Identity；Manifest、Locator、Snapshot、SHA256、ReverseChain 與 Package 則是可驗證的 Projection 與重建證據。

```text
🌱最小可逆種子
＋ 🪞空的幻影膠囊
＋ ⚖️A=A
→ 可逆、可重建、可投影、可自我解釋
```

## 唯一路線

```text
任何入口
→ 🧩LKMINI
```
